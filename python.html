1. Set the feed and design choices

Start on a 100 mol feed basis. Enter each feed mole fraction as a decimal and make them add to one. Here q = 0.50 means that half the feed moles are liquid. The design choices are the two key recoveries, the operating reflux multiplier, and the feed tray position.

Python lists start at index zero, so n-hexane and n-heptane have indices 1 and 2. The key pair is adjacent in volatility order. The code scales the volatilities so that the heavy key has α = 1, as in the lab.

from math import ceil, exp, floor, isclose, log, sqrt

feed_moles = 100.0
names = ["n-Pentane", "n-Hexane", "n-Heptane", "n-Octane"]
z = [0.25, 0.25, 0.25, 0.25]       # Feed mole fractions
alpha = [2.50, 2.00, 1.00, 0.70]  # Relative to the heavy key
light, heavy = 1, 2                # Python indices start at zero
q = 0.50                          # Liquid fraction of the feed
light_recovery = 0.95              # Sent to the distillate
heavy_recovery = 0.96              # Sent to the bottoms
reflux_multiplier = 1.50
feed_position = 0.50               # Top = 0, bottom = 1

if len(names) != len(z) or len(alpha) != len(z):
    raise ValueError("Give each component a name, feed fraction, and relative volatility.")
if not (0 <= light < heavy < len(z) and heavy == light + 1):
    raise ValueError("Choose adjacent light and heavy keys in volatility order.")
if not isclose(sum(z), 1.0) or any(fraction <= 0 for fraction in z):
    raise ValueError("Use positive feed mole fractions that sum to one.")
if not all(a > b > 0 for a, b in zip(alpha, alpha[1:])):
    raise ValueError("List the components in descending positive volatility.")
alpha = [value / alpha[heavy] for value in alpha]
if not 0 <= q <= 1 or not 0 <= feed_position <= 1:
    raise ValueError("Feed quality and feed position must be between zero and one.")
if not (0.5 < light_recovery < 1 and 0.5 < heavy_recovery < 1):
    raise ValueError("Choose key recoveries greater than 0.5 and below one.")
if reflux_multiplier <= 1:
    raise ValueError("Choose operating reflux above the minimum.")

# Course count after specifying the section tray pressures and heat duties.
components = len(z)
dof = (components + 13) - (components + 2) - 1 - 2 - 3 - 1

2. Apply the component material balance

The shortcut sends lighter nonkeys entirely to the distillate and heavier nonkeys entirely to the bottoms. The keys split between both products. For example, 96% of n-heptane enters the bottoms, leaving 4% in the distillate.

Multiply each feed amount by its fraction sent to the distillate. The remainder enters the bottoms. Divide each component amount by the total moles in its product to get its product mole fraction. These compositions set the separation target for Fenske and Underwood.

# Lighter nonkeys go overhead. Heavier nonkeys go to the bottoms.
# The adjacent keys are the two components that split between products.
fraction_to_distillate = (
    [1.0] * light
    + [light_recovery, 1.0 - heavy_recovery]
    + [0.0] * (components - heavy - 1)
)
feed_i = [feed_moles * fraction for fraction in z]
distillate_i = [
    moles * recovery for moles, recovery in zip(feed_i, fraction_to_distillate)
]
bottoms_i = [f - d for f, d in zip(feed_i, distillate_i)]
distillate = sum(distillate_i)
bottoms = sum(bottoms_i)
x_d = [moles / distillate for moles in distillate_i]
x_b = [moles / bottoms for moles in bottoms_i]

3. Calculate Fenske's minimum stage count

Divide the top light-to-heavy key ratio by the bottom ratio to find the enrichment required. At total reflux, one ideal contact multiplies the ratio by the key volatility ratio. Taking natural logs gives the minimum number of contacts. In that limit every mole of condensate returns to the column and no distillate is withdrawn.

top_ratio = x_d[light] / x_d[heavy]
bottom_ratio = x_b[light] / x_b[heavy]
key_volatility = alpha[light] / alpha[heavy]
n_min = log(top_ratio / bottom_ratio) / log(key_volatility)

4. Solve the Underwood equations

Underwood uses the feed composition and its vapor fraction, 1 − q, to find θ between the heavy- and light-key volatilities. The sum increases across this interval. At each midpoint, move the lower bound up when the sum is below 1 − q. Otherwise move the upper bound down.

Use the same θ with the distillate mole fractions, then subtract one to get minimum reflux. At that limit the composition change between stages approaches zero at a pinch. A working column needs higher reflux to reach the separation with finitely many stages.

def underwood_sum(composition, theta):
    return sum(a * x / (a - theta) for a, x in zip(alpha, composition))


# The feed sum increases between these two adjacent volatilities.
lower, upper = alpha[heavy], alpha[light]
for _ in range(80):
    midpoint = (lower + upper) / 2
    if midpoint in (lower, upper):
        break
    if underwood_sum(z, midpoint) < 1 - q:
        lower = midpoint
    else:
        upper = midpoint

theta = (lower + upper) / 2
if not alpha[heavy] < theta < alpha[light]:
    raise ValueError("The key volatilities are too close to resolve an Underwood root.")
r_min = underwood_sum(x_d, theta) - 1
if r_min <= 1e-12:
    raise ValueError("The key-root shortcut needs a positive minimum for the reflux multiplier.")

5. Estimate stages at working reflux

Multiply the minimum reflux by 1.50 to choose a working reflux. X measures how far the working reflux is above the minimum. The Gilliland fit gives Y, which measures how far the estimated number of stages is above Fenske’s minimum.

Round up to whole equilibrium stages and reserve one for the reboiler. The chosen feed position places the feed on one of the other stages. It allocates the trays above and below the feed without changing the total stage estimate.

r = reflux_multiplier * r_min
x = (r - r_min) / (r + 1)
exponent = (1 + 54.4 * x) / (11 + 117.2 * x) * (x - 1) / sqrt(x)
one_minus_y = exp(exponent)
if not one_minus_y:
    raise ValueError("Increase reflux to move away from the pinch.")
y = 1 - one_minus_y
stages = (n_min + 1) / one_minus_y - 1

# Round up and reserve one stage for the reboiler.
whole_stages = max(2, ceil(stages))
trays = whole_stages - 1
trays_above_feed = floor(feed_position * (trays - 1) + 0.5)
feed_tray = trays_above_feed + 1
