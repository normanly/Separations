Worked degrees-of-freedom calculation

Degrees of freedom equal unknowns minus independent equations. This count uses the course column with a rectifying section, a stripping section, one feed tray, a condenser, a reflux drum that splits liquid, and an equilibrium reboiler.

Assemble the column

Let C be the number of components (currently 4), and let T be the number of rectifying and stripping trays combined, excluding the feed tray and reboiler. The standalone counts use the course convention.

Each section with n trays contributes 2n + 2C + 5 after its internal connections are counted. Add both sections, the feed tray, condenser, reboiler, and reflux splitter:

[2T + 4C + 10] + [3C + 8] + 2[C + 4] + [C + 5] = 2T + 10C + 31

Count the nine streams shared between those units once. Each shared stream has C + 2 independent variables: total flow, C − 1 mole fractions, temperature, and pressure.

2T + 10C + 31 − 9(C + 2) = 2T + C + 13

Why the inlet is editable

The inlet uses C + 2 specifications: one flow basis, C − 1 independent mole fractions, and two thermal-state properties (temperature and pressure in the course count). Each run fixes these values. Editing them defines a new feed case with the same number of independent design choices. The lab fixes the flow basis at 100 mol and represents the inlet phase condition through feed quality q at the assumed pressure.

  • Composition. With four components, three feed mole fractions are independent. The fourth equals 100% minus their sum. Keep the total at 100% when changing the feed. At fixed recoveries, a different feed composition changes the product flows and compositions and can change minimum reflux.
  • Feed quality. Changing q changes the right-hand side 1 − q of Underwood’s feed equation. It can therefore change the minimum reflux and the operating stage estimate. With key recoveries and relative volatilities held fixed, Fenske’s minimum stages stay the same.

Model notes

This shortcut model uses constant relative volatility α for the light key (αLK = α, αHK = 1), constant molar overflow, a total condenser, and an equilibrium reboiler. Gilliland’s stage count includes the equilibrium reboiler. For tray allocation, the lab rounds up and allows at least one feed tray plus the reboiler. The specified fraction of inter-tray positions above the feed sets its location by rounding to the nearest tray. Hydrocarbon mixtures load illustrative relative volatilities. Use a value appropriate to the mixture, temperature, and pressure for engineering calculations.

Equilibrium and feed state

With constant relative volatilities, yi = αixi / Σ αjxj. For an ideal mixture at a given temperature, Raoult’s law relates α to the ratio of saturation pressures, which can be estimated from Antoine’s equation. For a partially vaporized feed, q = 1 − β, where β is the vapor fraction from a flash calculation.

Fenske at total reflux

The ratio of light to heavy key in the distillate divided by that ratio in the bottoms determines Nmin.

Underwood at minimum reflux

Find θ between 1 and α from Σ αizi / (αi − θ) = 1 − q. Then evaluate Rmin + 1 = Σ αixD,i / (αi − θ). Here q is the liquid fraction of the feed in the selected range, from saturated vapor (0) to saturated liquid (1). The reflux multiplier requires a positive Rmin.

Gilliland at finite reflux

Set X = (R − Rmin) / (R + 1) and Y = (N − Nmin) / (N + 1). The exponential fit to the Gilliland correlation gives Y from X.

Y = 1 − exp[((1 + 54.4X) / (11 + 117.2X)) · ((X − 1) / √X)]

Recover N = (Nmin + Y) / (1 − Y). The design curve approaches the minimum stage count as reflux increases and rises sharply as reflux approaches Rmin. The normalized view shows both endpoints directly.
